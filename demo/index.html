See Mehfil working

A three-minute walkthrough of the iPhone app, recorded on a simulator with the built-in sample season: twelve events, a crew of 28, inventory and ₹23.5 lakh in receivables. It follows one real problem, two Saturday events that both need the same decor team, from the warning on the home screen to the one-tap fix. Mehfil is a complete operations app for Indian wedding vendors, native on iOS and Android over a shared Firebase backend. Everything in the film is running code from the sale; nothing is a mock-up.

Status: complete and working on both platforms. Never submitted to the App Store or Google Play; no users, no revenue.

Run it yourself

Neither app needs an account, a key or a backend to run. Without a Firebase config file, each starts in device-only mode: the welcome screen offers Continue on this device and keeps everything on the device, so the whole product works from a fresh checkout in about ten minutes.

The repositories are private. Email for read access to mehfil-ios, mehfil-android, mehfil-backend and mehfil-design.

iPhone

Needs a Mac with Xcode 26 (iOS 26 SDK).

  1. Clone mehfil-ios and open Mehfil.xcodeproj.
  2. To start with the sample data shown in the film, set case .sampleSeason: true in Mehfil/Model/FeatureConfig.swift. It ships off so a production build never contains demo data.
  3. Choose the Mehfil scheme and an iPhone simulator, then press Run. The first build downloads the Firebase and Google Sign-In packages, which takes a few minutes. If Xcode asks for a signing team, pick your own Apple ID; a free account is fine.
  4. Tap Continue on this device, enter any name and business, leave Start with a sample season on, and open Mehfil.

Android

Needs Android Studio 2025.3 or later (Gradle 9.4, AGP 9.2, min SDK 26).

  1. Clone mehfil-android and open the folder in Android Studio.
  2. For the sample data, set SAMPLE_SEASON(true) in app/src/main/java/com/mehfil/app/model/FeatureConfig.kt.
  3. Run on an emulator or a phone with Android 8.0 or later.
  4. Onboarding is the same as on iPhone.

To switch on real accounts, drop in a GoogleService-Info.plist or google-services.json; the setup is in mehfil-backend.

Try the Android app without the code

A release build in device-only mode with the sample season on. It keeps everything on the phone and sends nothing to any server.

Download the APK

4.6 MB · Android 8.0 or later. It is signed with a standard debug key rather than a store key, so Android will warn that it comes from an unknown source. Allow installs from your browser or file manager when prompted, and uninstall it when you're done.
